設定

再生を転送音声拡張機能

再生を転送

再生した動画を、ジャンルごとのDiscordへ。

キーとWebhook URLはWindowsの暗号化ストレージに保存します。通知は保存後の再生から有効です。

フォーマットで使える変数

日付は日本時間。低評価数など取得できない値は「取得不可」と表示します。通知によるメンションは無効です。

音声

プレイヤー内の「音量補正」ボタンでも切り替えできます。YouTubeの内部仕様に依存します。「一定音量 / Stable volume」はYouTube側でOFFにしてください。

Windowsの既定の出力デバイスに自動で切り替わります。ヘッドホンの接続・取り外し後も、プラグインを挿し直す必要はありません。

Chrome拡張機能

専用フォルダーに、拡張機能ごとの展開済みフォルダーを置いてください。

例: Extensions / YouTubeEnhancer / manifest.json

起動時に自動で読み込みます。追加・削除の反映時はYouTubeを再読み込みします。既存ファイルの更新後はアプリを再起動してください。ZIP・CRXは展開が必要です。Electronが対応していないAPIを使う機能は動作しない場合があります。
